# 기존 Steam 키보드용 한글 조합 보강 — 실험판

Steam의 키보드 화면·터치·트랙패드 조작은 유지하고, **데스크톱 한국어 키보드의
IBus 키 처리만** 로컬 `libhangul` 조합기로 연결하는 실험적 보강입니다.
별도 화면 키보드를 띄우거나 시스템 한글 입력기를 교체하지 않습니다.

Steam의 한국어 키 입력을 순서대로 처리하고, 자체 조합기에서 계산한 현재 음절의
차이만 Steam의 기존 문자 전송 함수로 전달합니다. 기존 앱의 입력 내용은 읽지 않습니다.
이 보강이 관리하는 현재 음절만 메모리에 유지하며 입력을 파일이나 원격 서버에 기록하지 않습니다.

## 설치 및 사용

스팀덱 데스크톱 모드에서 Steam 키보드를 닫고, 이 폴더에서 실행합니다.

```bash
bash install.sh
```

그다음 원래 입력칸을 선택하고 평소처럼 **Steam + X**로 키보드를 열어 한국어로 입력합니다.
별도 조합창에서 복사할 필요가 없습니다.
설치 직후나 Steam을 완전히 다시 시작한 직후에는 처음 키보드를 열고 약 2초 기다린 뒤
닫았다 다시 열어 사용하세요. 처음 연결할 때 Steam 내부 키보드 클래스를 찾는 시간이 필요합니다.

- 일시 중지: `systemctl --user stop deck-steam-hangul.service`
- 다시 시작: `systemctl --user start deck-steam-hangul.service`
- 상태: `systemctl --user status deck-steam-hangul.service`
- 제거: `bash ~/.local/share/deck-steam-hangul/uninstall.sh`

중지하면 연결을 해제하고 원래 Steam 함수를 복원합니다. 서비스가 갑자기 종료되면
키보드 쪽 watchdog이 약 3.5초 뒤 원래 함수를 복원합니다. 문제가 생기면 서비스를
중지하고 키보드를 닫았다 다시 여세요.

## 요구사항과 범위

- Python 3, libhangul, PyGObject, libsoup 3 및 AT-SPI 2가 필요합니다.
- Steam의 **기존 로컬 CEF 디버깅 인터페이스**가 필요합니다. 보강 서비스가 원격 디버깅을
  새로 켜거나 네트워크 인터페이스를 열지는 않습니다. 현재 스팀덱의 로컬 포트 8081/8080을 조사합니다.
- Steam 내부 React 컴포넌트와 IBus 바인딩에 연결하므로 Steam 업데이트로 호환성이 깨질 수 있습니다.
  알려진 구조를 찾지 못하면 설치하지 않고 기다리며, 처리 실패 시 원래 IBus 경로로 돌려보냅니다.
- 현재 데스크톱의 `bStandalone` 한국어 키보드만 대상으로 합니다. 영어 등 다른 언어는 원래 경로를 사용합니다.
- 기존 앱의 다른 입력칸으로 포커스가 바뀌면 조합 상태를 새로 시작합니다.
- 같은 입력칸 안에서 커서를 손으로 옮기거나 선택 영역을 편집하는 모든 경우는 아직 검증되지 않았습니다.
  입력 위치를 바꾼 뒤 문제가 생기면 키보드를 닫았다 다시 열어 새 조합을 시작하세요.
- 콘솔의 Enter는 실제 Enter로 전달됩니다. 보강은 입력 문자를 해석하거나 명령을 만들어 실행하지 않습니다.

## 검증

```bash
python3 -m unittest -v
node --test patch.test.cjs
```

조합 테스트는 실제 libhangul로 현대 한글 11,172개, 받침·겹받침·이어쓰기·삭제를 검사합니다.
`word-cases.json`의 `거짓`, `의술`, `우유곽` 등 13개 단어도 조합 결과와 공백 확정을 검사합니다.
연결 테스트는 키 순서, 원래 언어 입력 유지, IBus reset으로 인한 조합 초기화 차단,
서비스 실패 시 원래 함수 복원을 검사합니다.
조합기와 연결 테스트 통과는 모든 앱에서의 정상 동작을 뜻하지 않습니다. 실기 검증 결과를 별도로 확인해야 합니다.

현재 확인한 실제 입력과 한계는 [VERIFICATION.md](VERIFICATION.md)에 정리했습니다.
