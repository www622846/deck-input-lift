# Steam 키보드 보강 실기 검증 — 2026-11-08

대상은 기존 Steam의 한국어 데스크톱 키보드다. 별도 키보드 UI를 사용하지 않았다.

- Steam 키보드의 기존 터치 처리로 `거짓 값 읽어 `를 입력했다.
- 격리한 GTK Wayland 입력칸에서 위 문자열을 확인했다. 개인 앱의 입력 내용은 읽지 않았다.
- 보강 상태에서 18개의 글쇠가 처리되고, 원래 경로로의 fallback은 0회였다.
- 키보드를 닫았다 다시 열어 첫 조합부터 새 처리 경로를 사용하는 것을 확인했다.
- `ㄱ → ㅓ → ㅈ → ㅣ` 입력 뒤 Steam의 원래 IBus context reset을 요청하고,
  이어서 `ㅅ`을 눌렀을 때 `거짓`으로 입력됐다. 6개의 글쇠가 보강 경로로 처리됐고 fallback은 0회였다.
- 조합기/편집 변환 Python 테스트 27개와 연결 JavaScript 테스트 8개가 통과했다.
  조합기 테스트에는 현대 한글 11,172개 전체 조합이 포함된다.

이 검증은 한 대의 Steam Deck에서 테스트 입력칸과 실제 Steam 터치 경로로 수행했다.
트랙패드도 같은 TypeKeyInternal → IBus 처리 함수를 사용하지만 물리 컨트롤러로의 입력은
자동 검증하지 않았다. Firefox, Konsole, 임의의 앱에서 모든 편집 동작이 해결됐다는 의미는 아니다.
동일 입력칸 내 커서 이동·선택 편집 등은 추가 검증이 필요하다.

Steam의 공유 키보드 클래스에 연결하므로 키보드를 다시 열 때 첫 글자 처리 전에
해당 컴포넌트를 연결한다. Steam을 완전히 다시 시작한 직후에는 최초 키보드 창에서
내부 클래스를 찾는 시간이 필요할 수 있다. 실험판이므로 처음에는 키보드를 연 뒤
잠시 기다렸다 닫고 다시 열어 사용한다.
